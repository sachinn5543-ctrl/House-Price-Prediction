# 🏠 House Price Prediction

This project predicts house prices using Machine Learning.

## 📌 Project Overview
The goal of this project is to build a machine learning model that predicts house prices based on features such as:
- Area
- Number of bedrooms
- Bathrooms
- Location
- Stories
- Parking

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit


## 🚀 Project Structure
data/ → dataset  
notebooks/ → EDA & experiments  
src/ → training & prediction scripts  
models/ → saved ML model  
app/ → Streamlit web app

## 🎯 Goal
Build an end-to-end ML project and deploy it as a web app.
